# [ youdownloader ]

**The ultimate terminal video downloader.**

A simple wrapper around yt-dlp to make downloading videos from YouTube and other sites a breeze.

### ➔ Installation
\`\`\`bash
curl -L sh.serghini.me/youdownloader -o youdownloader.sh
chmod +x youdownloader.sh
./youdownloader.sh
\`\`\`
